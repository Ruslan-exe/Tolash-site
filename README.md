# Tolash — сайт-визитка

Две страницы:

1. **Главная** (`index.html`) — для инвесторов и новых пользователей: идея, как работает,
   продукт, рынок, конкуренты, бизнес-модель, roadmap, цели и задачи, «Инвесторам»,
   «Обо мне», «Как начать», FAQ.
2. **Инструкция для рекламы** (`guide/index.html`) — скрытая страница-прогрев: какие
   вкладки есть в приложении и чем они помогают, первый счёт за 5 шагов, пример честного
   расчёта, сценарии, вопросы. Все кнопки ведут в бота.

Три языка: RU / UZ / EN. Все кнопки «Открыть в Telegram» ведут на https://t.me/Tolash_uz_bot.

## Как открыть

Дважды кликните `index.html` (или `guide/index.html`) — откроется в браузере.
Ничего устанавливать не нужно. Для шрифта Inter нужен интернет; без него — системный шрифт.

## Страница-инструкция для таргетированной рекламы

Адрес после публикации: `https://<ваш-сайт>/guide/`

- На главной нет ни одной ссылки на эту страницу, а в коде стоит `noindex, nofollow` —
  поисковики её не покажут. Попасть на неё можно только по прямой ссылке из рекламы.
  (Поставить пароль на статичный сайт нельзя — кто знает адрес, тот откроет.)
- Язык можно задать в ссылке: `/guide/?lang=uz`, `/guide/?lang=ru`, `/guide/?lang=en`.
  Без параметра язык берётся из настроек телефона.
- Метка источника (необязательно): `/guide/?start=insta1` — кнопки поведут на
  `t.me/Tolash_uz_bot?start=insta1`, и в боте будет видно, из какой рекламы пришёл человек.
  Используйте, только если бот умеет обрабатывать такие метки (`/start insta1`);
  иначе давайте ссылку без `start`.
- На телефоне внизу появляется закреплённая кнопка «Открыть Tolash в Telegram»,
  на компьютере в конце страницы — QR-код.
- Экраны приложения на странице нарисованы кодом (макеты). При желании их можно
  заменить реальными скриншотами.

## Язык

Определяется автоматически по языку браузера, переключается кнопками RU / UZ / EN
и запоминается (общий для обеих страниц). Прямые ссылки: `index.html?lang=uz` и т. д.

## Как выложить в интернет (бесплатно, 5 минут)

1. На GitHub создайте репозиторий, например `tolash-site`, загрузите в него
   все файлы этой папки (index.html, guide/, css/, js/, assets/).
2. Settings → Pages → Deploy from a branch → `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/tolash-site/`, инструкция — `.../tolash-site/guide/`.
4. Для красивого превью ссылки в Telegram замените в `<meta property="og:image">`
   относительный путь на полный адрес картинки, например
   `https://<ваш-логин>.github.io/tolash-site/assets/logo-wordmark.png`.

Альтернативы: Cloudflare Pages, Netlify, Vercel — везде достаточно перетащить папку.
